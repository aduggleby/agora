Implements the approved minimal Settings design.

- Compact connection card, clear expiry explanation and a streamlined Launch at login row.
- Separate area and full-screen shortcut recorders. Click a selector and press a combination containing Control, Option or Command; Escape cancels.
- Existing presets migrate automatically. Duplicate and unavailable shortcuts are rejected without overwriting the previous choice.
- Capture hotkeys pause during recording and resume on completion, cancellation or leaving Settings.
- 30 tests include shortcut migration, independent persistence, event conversion and validation.

Requires macOS 14+. The ZIP filename identifies its CPU architecture. This is an ad-hoc signed development preview, not a notarized distribution build. See the client README for signing/build instructions. The server is released separately.
